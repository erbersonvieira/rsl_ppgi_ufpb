# rsl_ppgi_ufpb
Esta Revisão Sistemática da Literatura (RSL) propõe-se a mapear e sintetizar o estado da arte do uso de guias táteis, objetos físicos, utilizados para prover feedback tátil em RVI. Buscou-se também investigar os principais métodos utilizados para avaliar o impacto desta abordagem sobre os efeitos cognitivos de Presença e Senso de Agência (Sense of Agency – SoA)
